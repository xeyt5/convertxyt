# Software de terceros

Los instaladores de convertxyt incluyen estos programas sin modificar, como
ejecutables independientes. Cada uno conserva su propia licencia, que no cambia
por ir incluido aquí.

| Programa | Licencia | Código fuente |
|---|---|---|
| [FFmpeg](https://ffmpeg.org) y ffprobe (compilaciones de yt-dlp/FFmpeg-Builds) | [GPL v3 o posterior](https://www.gnu.org/licenses/gpl-3.0.html) | [FFmpeg](https://ffmpeg.org/download.html), [scripts de compilación](https://github.com/yt-dlp/FFmpeg-Builds) |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | [Unlicense](https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE) | [yt-dlp](https://github.com/yt-dlp/yt-dlp) |
| [Deno](https://deno.com) | [MIT](https://github.com/denoland/deno/blob/main/LICENSE.md) | [Deno](https://github.com/denoland/deno) |

Las versiones exactas de cada instalador se pueden consultar en el registro de
la versión de GitHub Actions que lo generó.
